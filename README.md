# ML-Based-Cyber-Attack-Detection-in-Simulated-Networks
End-to-end ML intrusion detection system: 8 hand-captured PCAPs from a GNS3 lab → 34 engineered flow features → Random Forest at 99.74% accuracy → live Flask dashboard detecting Ping DoS, SYN Flood, Nmap Scan and SSH Brute Force in real time. Built with Python, Scapy, scikit-learn and Kali Linux.
